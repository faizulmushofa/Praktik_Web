# Praktik Web — Kopi Nusantara

Landing page Kopi Nusantara menggunakan Tailwind CSS v4 CLI.

## Prasyarat

- [Node.js](https://nodejs.org/) (versi 18+)

## Cara Menjalankan

1. **Install dependensi:**
   ```bash
   npm install
   ```

2. **Build CSS:**
   ```bash
   # Sekali build
   npm run build-css

   # Atau mode watch (auto update saat file diubah)
   npm run watch-css
   ```

3. **Buka aplikasi:**
   Buka file `apps/index.html` di browser (atau gunakan ekstensi Live Server di VS Code).
